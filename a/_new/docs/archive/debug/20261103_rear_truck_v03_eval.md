## 한눈에 보기

**11-03에 기준을 다시 고정하고 처음부터 다시 평가했다.** 보드와 같은 3클래스(차량·moto·person)로 매칭하고, v02와 갈린 박스 1,476개를 지난 판정 없이 새로 판정했다. 같은 데이터로 다시 학습만 한 F0를 기준선으로 삼아 "우연한 흔들림"과 "실제 변화"를 갈랐다.

- **오인식 감소는 진짜다.** 배경을 더 학습한 네 모델은 v02의 오인식을 절반 가까이 없앴다(+166~+225). 다시 학습만 한 F0는 −20으로 줄지 않았다.
- **객체 손실도 진짜다.** 배포 임계값(각자 6,152장 optimal) 그대로면 FT −38, G1 −44, F1 −68, 새 모델 −81개를 잃는다. 재학습 흔들림(±17)을 크게 벗어난다. 잃는 객체는 작거나 먼 객체가 아니라 옆 차로의 중간~큰 객체다.
- **가장 나은 후보는 FT다.** 오인식 +166, 객체 −38(차량 −18, person −20)로 네 모델 중 잃는 객체가 가장 적고, iputest AP50도 가장 높다(.381 대 v02 .358).
- **잃은 객체 대부분은 임계값 바로 아래다.** FT가 놓친 85개 중 56개가 임계값보다 0.05도 안 낮았다. 임계값을 다시 고르면 손실을 줄일 여지가 크다.

> **지금 상태:** 배포 임계값 그대로는 v02를 대체할 모델이 없다. 다음 단계는 FT 임계값을 6,152장 재현율 맞춤으로 다시 고르고, 같은 판정으로 "오인식은 크게 줄고 놓침은 흔들림 범위 안"인지 확인하는 것이다. 허용 손실 기준은 아직 확정하지 않았다(제안: 재학습 흔들림 안, 객체 순변화 −17 이상).

## 왜 이렇게 나왔나

1. **배경 학습은 점수를 전반적으로 낮춘다.** 오인식 점수가 크게 내려가 화면에서 사라지고, 실제 객체 점수도 조금 내려가 임계값 아래로 떨어진다. FT가 놓친 객체 85개 중 56개는 임계값보다 0.05 이내로 낮았고, 아예 못 본 수준(0.15 넘게 낮음)은 8개뿐이다.
2. **박스 순서를 매기는 실력은 FT가 더 낫다.** iputest AP50 .381 대 v02 .358. 임계값만 맞추면 두 마리 토끼를 잡을 여지가 있다는 뜻이다.
3. **bg v4 전체(차량 배경 포함)를 넣은 새 모델·F1은 차량을 크게 잃는다**(−48~−54). FT·G1은 차량 손실이 그 절반 아래다.
4. **재학습만으로도 객체 30~40개가 서로 바뀐다.** 그래서 모델 하나를 한 번만 비교하면 작은 차이는 우연일 수 있다. F0 기준선으로 이걸 걸러냈다.

## 한계와 주의점

- 기준선은 F0 하나다. F0는 v02에서 이어서 학습한 모델이라, 처음부터 다시 학습한 경우보다 흔들림이 작게 잡혔을 수 있다.
- 판정은 한 사람이 했다. 검토는 B 기준 손실·획득 카드에 집중했고 C 기준 카드는 다시 보지 않았다.
- 차량 겹침 처리 임계(IoU 0.45)는 보드 설정을 확인하지 않은 가정이다.
- 보드 점수는 몇 단계로만 나온다(예: car .3~.55 사이 4단계). 임계값을 조금만 바꿔도 결과가 크게 튀 수 있다.
- iputest 이미지 일부가 학습 배경에 들어가 있었다(md5 동일, FT 29 / G1 10 / 새 모델·F1 48장, 모두 GT가 빈 배경). 빼고 계산해도 거의 같았다.
- v5hn은 iputest와 기간·카메라가 같다. FT에 유리할 수 있다.

### 평가 방법

최종 판단은 iputest 1,481장 보드 결과로 한다. 11-03부터는 보드와 같은 3클래스로 매칭하고, 모델마다 6,152장 보드 optimal 임계값(B)으로 띄운 결과를 v02와 비교한다. 두 모델의 결과가 갈린 박스를 사람이 판정하고, 같은 데이터로 다시 학습만 한 F0의 결과를 "흔들림" 기준선으로 쓴다. 11-02까지의 5클래스·재현율 맞춤 결과는 부록에 남긴다.

- B 임계값: customEval 이 0~1을 1,001칸으로 나눠 F1이 가장 높은 지점(optimal)을 고른다. 5클래스별 값을 먼저 적용하고 차량으로 묶는다.
- 판정 카드 두 종류
  - 검출 박스(GT와 안 맞은 박스): 실제 객체(GT 누락) / 애매 / 진짜 오인식. 3클래스가 다르면 진짜 오인식
  - GT 박스: 진짜 객체 / 놓쳤도 됨 / GT 오류
- 계산식
  - 객체 순변화 = (TP 획득·진짜 객체 + FP 신규·실제 객체) − (TP 손실·진짜 객체 + FP 제거·실제 객체)
  - 오인식 순감소 = FP 제거·진짜 오인식 − FP 신규·진짜 오인식
  - ‘애매’, ‘놓쳤도 됨’, ‘GT 오류’는 어느 쪽에도 세지 않는다. 유의성은 부호 검정.
